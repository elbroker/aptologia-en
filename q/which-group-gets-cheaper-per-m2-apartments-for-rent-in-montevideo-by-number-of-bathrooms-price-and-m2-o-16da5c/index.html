Which group gets cheaper per m²?

For square meter, the cheapest is "3 bathrooms" (538.5 Uruguayan pesos (USD 13.4) / m² per month) and the most expensive "1 bath" (591.6 Uruguayan pesos (USD 14.7) / m² per month).
