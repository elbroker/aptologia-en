How much does the rent increase an apartment with parking and a closed set?

+ 18.5% against a comparable one without parking, set or balcony.

In Colombia, an apartment for rent with the three is requested + 33.1% in front of one without any of the three amenities (parking lot, closed set and balcony) of the same city, estrato, rooms and area range; with only closed set, + 4.8%. The most common combination in the offer is three (45.7% of the ads).
